What you see here is what your key can read — the endpoints its scopes cover, and the public ones — with “Try it” on each.

No key yet?
  1. Sign in at nswpsn.forcequit.xyz and request one from your profile, under API keys, saying what it is for.
  2. Staff look at the request and choose what the key may read.
  3. Once it is approved, press Generate key on the same card. The key is shown once — keep it somewhere safe.

The key stays in this browser tab only and is sent to this API and nowhere else. AusAware relays publicly available feeds; it is not affiliated with any agency whose data it carries.
